# Build from source

## Requirements

Windows 11 with Visual Studio 2022 (17.14 or later) or its Build Tools, including the
*Desktop development with C++* and *WinUI application development* workloads and the Windows 11 SDK.
NuGet restores the Windows App SDK, C++/WinRT, WIL and Win2D (`Microsoft.Graphics.Win2D`); versions are
pinned in `Directory.Packages.props`.

## Build

From a *Developer PowerShell for VS 2022*:

```powershell
msbuild Eikon.sln /t:Restore /p:Configuration=Release /p:Platform=x64
msbuild Eikon.sln /m /p:Configuration=Release /p:Platform=x64
```

Use `/p:Platform=ARM64` for ARM64. Or open `Eikon.sln` in Visual Studio, pick x64 or ARM64 and press
<kbd>F5</kbd>: the app is an MSIX package, and F5 registers it for the current user.

## Tests

Core logic (settings, URL parsing, geometry, colours, JSON, the annotation objects, stitching, the
Library index, …) has a console test runner in `tests/Eikon.Core.Tests`. It builds with the solution
and has no WinRT dependency (Core is plain C++20; the runner keeps settings in memory):

```powershell
tests\Eikon.Core.Tests\bin\x64\Release\Eikon.Core.Tests.exe
```

It prints one `[ OK ]` or `[FAIL]` line per test and exits with the number of failed checks.

## Sideload package

To install Eikon outside Visual Studio, build a signed MSIX with a certificate of your own. The
package's publisher is `CN=Eikon`, so the certificate's subject must match:

```powershell
$cert = New-SelfSignedCertificate -Type Custom -Subject "CN=Eikon" -KeyUsage DigitalSignature `
  -CertStoreLocation Cert:\CurrentUser\My `
  -TextExtension @("2.5.29.37={text}1.3.6.1.5.5.7.3.3", "2.5.29.19={text}")
$password = Read-Host -AsSecureString "PFX password"
Export-PfxCertificate -Cert $cert -FilePath Eikon.pfx -Password $password
Export-Certificate -Cert $cert -FilePath Eikon.cer

msbuild Eikon.sln /m /p:Configuration=Release /p:Platform=x64 `
  /p:GenerateAppxPackageOnBuild=true /p:UapAppxPackageBuildMode=SideloadOnly /p:AppxBundle=Never `
  /p:AppxPackageSigningEnabled=true /p:PackageCertificateKeyFile=$PWD\Eikon.pfx `
  /p:PackageCertificatePassword=<password>
```

The package and its framework dependencies land in `src\Eikon\AppPackages\`. Trust the certificate
once (an elevated `Import-Certificate -FilePath Eikon.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople`),
then install the `.msix` by double-clicking it or with `Add-AppxPackage`. `.github/workflows/build.yml`
does the same in CI with a throwaway certificate.

## Generated assets

The app icon, MSIX logos, `.ico`, brand images, Lucide icons, cursors and drawings in
`src/Eikon/Assets` are generated by scripts and committed. To regenerate them, install
[uv](https://docs.astral.sh/uv/) and run from the repository root:

```sh
uv run --with resvg-py==0.5.0 --with pillow python tools/generate_assets.py
uv run --with resvg-py==0.5.0 --with pillow python tools/generate_icons.py
```

`tools/merge_resw.py` merges two edited copies of `Strings/en-US/Resources.resw` when a merge conflicts.
